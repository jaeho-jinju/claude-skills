# 팀 테스트 전략 자동 적용기 (라우터)

테스트 작성·보강 작업의 **진입점**입니다. 대상 파일만 결정하고, 실제 작업은 `test-writer` 서브에이전트에 위임하여 메인 컨텍스트를 가볍게 유지합니다.

## 인자

- **파일경로** (필수): 테스트할 소스 파일의 경로 (예: `src/pages/niceAuth/niceAuth.utils.ts`)
- **함수명** (선택): 파일 내 특정 함수만 대상으로 할 때 (예: `isValidNiceAuthInput`)

호출 예시:
- `/my-test src/pages/niceAuth/niceAuth.utils.ts` → 파일 전체
- `/my-test src/pages/niceAuth/niceAuth.utils.ts isValidNiceAuthInput` → 함수만
- `/my-test` (인자 없음) → git 변경사항 기반 자동 탐지
- 자연어: "niceAuth.utils.ts 테스트 작성해줘", "NiceAuthPage 테스트 보강해줘"

## 절차

### Step 1: 대상 파일 결정

다음 **우선순위**로 대상 파일을 결정한다:

#### 1순위 — 인자로 파일경로 지정됨
인자로 받은 경로를 그대로 사용. 함수명 인자도 같이 있으면 해당 함수만 대상.

#### 2순위 — 인자 없음 (`/my-test` 단독 호출) → git 변경사항 기반 자동 탐지
```bash
# 변경된 src/ 하위 .ts/.tsx 파일 (테스트 파일 제외)
git status --porcelain | awk '{print $2}' \
  | grep -E '^src/.+\.(ts|tsx)$' \
  | grep -v '__tests__'
```

- **1개 발견** → 그 파일을 자동 선택하고 진행.
- **여러 개 발견** → 사용자에게 어떤 파일(들)을 테스트할지 선택지 제시. 모두 처리도 가능.
- **0개 발견** → 3순위(자연어 맥락) fallback.

> 이 모드는 "방금 수정한 코드의 테스트 작성/보강" 흐름과 정확히 맞물림.

#### 3순위 — 자연어로 이름만 언급 (예: "NiceAuthPage 테스트 작성해줘")
```bash
# a. 정확한 파일명 매치 우선
find src -type f \( -name "{이름}.ts" -o -name "{이름}.tsx" \
  -o -name "{이름}.utils.ts" -o -name "{이름}.reducer.ts" \)

# b. 매치 없으면 심볼명 기반 탐색
find src -type f \( -name "*.ts" -o -name "*.tsx" \) \
  | xargs grep -l "export.*{이름}\|class {이름}\|function {이름}"
```
- 후보 여러 개 → 사용자 확인.
- 후보 0개 → 사용자에게 정확한 경로 요청.

#### 4순위 — 위 어디에도 해당 안 됨
사용자에게 "어떤 파일을 테스트할까요?"라고 질문.

### Step 2: 서브에이전트 위임

대상 파일이 결정되면 **Agent 툴(subagent_type=test-writer)** 을 호출한다.

**위임 프롬프트 형식**:
```
대상 파일: <파일경로>
함수명: <함수명 or "없음 (파일 전체)">

팀 테스트 전략에 따라 위 파일의 테스트를 작성하거나 보강해주세요.
타입(유닛/컴포넌트)과 모드(생성/보강)는 자동 감지하고,
완료 후 결과 보고 형식대로 반환해주세요.
```

여러 파일이 선정된 경우 각 파일마다 별도 호출 또는 한 번에 모든 파일을 위임. (test-writer가 순차 처리 가능)

### Step 3: 결과 보고

서브에이전트로부터 받은 결과를 사용자에게 그대로 전달한다. 메인 에이전트는 결과를 추가 가공하지 않고 다음 행동을 사용자에게 안내한다.

## 메모

- 실제 테스트 작성 규칙(분기 분석, 픽스처 패턴, Mock 구조, Given-When-Then, Import 패턴 등)은 모두 `test-writer` 서브에이전트(`~/.claude/agents/test-writer.md`)에 정의되어 있음.
- 이 스킬은 **대상 파일 결정 + 위임 + 결과 전달**만 담당.
- 규칙 변경이 필요하면 `test-writer.md`를 수정.
